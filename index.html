Integrated, with no plugins to install

The core of AMO Commander is compiled into one program. Extra helpers are optional and only widen what the viewer and archive tools can open.

Built in

  • PDF viewer: PDFium engine, embedded
  • Media information: MediaInfo engine, embedded (codec, container, duration, bitrate, resolution, frame rate, channels, sample rate)
  • Images: JPG, PNG, GIF, BMP, TIFF, ICO, WMF, EMF
  • Code editor: Scintilla and Lexilla with Geany filetype data and 46 colour schemes. Symbols for C/C++, Python, JavaScript/TypeScript, PHP, Ruby, Lua, Perl, Go, Rust, shell, batch, Markdown, INI/TOML, Make, SQL, Pascal, Basic, LaTeX, Haskell, Lisp and YAML
  • Documents: uses the preview handlers already in Windows (for example Office, if installed)
  • FTP client and server, network browsing, checksums, compare and sync, multi-rename
  • Scanner support (WIA), printing, and fonts embedded in the program

Optional helpers

  • 7-Zip: archive browsing, packing and unpacking
  • IrfanView, XnView NConvert or ImageMagick: extra image formats such as WEBP, HEIC, AVIF, camera RAW, PSD, SVG, TGA, DDS, JP2, EPS and AI. The app finds them automatically
  • FFmpeg: video frames and conversion
  • Not found? The app falls back to its built-in viewer. A helper install script is included.
