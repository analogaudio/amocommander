F10

Duplicate finder

  • Scan one or many folders, with subfolders and a minimum size. Also Ctrl+Shift+D.
  • Match by identical content (size, then SHA-256 of the first 64 KB, then of the whole file), or the fast same name and size / same size and date.
  • Mark with a click or Space, or Keep newest, oldest or first.
  • Delete marked or Move marked through the queue, to the Recycle Bin when possible.
  • At least one copy of each group is always kept, and files are re-checked before anything is queued.

Copy / transfer details

  • Four tabs: Sources, Transfers, History and Log.
  • Every job shows status, progress, speed and ETA. Copy, move and delete start automatically, and queued jobs follow when the others finish.
  • Skip file, Pause, Cancel, Retry failed, Retry as administrator, Open destination.
  • Verify with checksums, then save an HTML or CSV report. Move deletes the original only after the copy is checked.
  • Shift+F11 pauses everything, Ctrl+F11 shows or hides the queue panel. Esc closes the window and jobs keep running.

Method stack

New name with tags, Replace (plain text or regular expression with $1 $2), Add text, Remove, Change case, Numbering, Trim / clean and Extension, applied from top to bottom.

Tags

<Name> <Ext> <Inc> <Parent> <Size> <Date> <Time> <Created> <Now> <Year> <Month> <Day> <Hour> <Min> <Sec>. The older [N] [E] [C] [D] [T] tags still work.

Three outputs

Rename in place with Undo, or Move or Copy to a folder using the new names. Moves and copies go through the verified transfer queue.

Safe by design

Name swaps and case-only changes work. Reserved names (CON, NUL, COM1...), names over 255 characters and long paths are flagged. Presets (.amorn) save your method stack.

How it matches

  • Identical content. Compares size first, then a SHA-256 of the first 64 KB, then of the whole file. Only true copies are grouped.
  • Fast modes. Same name and size, or same size and modified time, when you want speed over a byte-exact check.
  • Options. Include subfolders, set a minimum size, drag folders in or use Add folders. Also opens from Find files.

How it clears

  • Mark. Click a box or press Space. Or Keep newest, Keep oldest or Keep first.
  • Delete or move. Marked files go through the transfer queue, to the Recycle Bin when the drive has one.
  • Always one left. At least one copy of every group is kept, and each file is checked again (size and date) before anything is queued.
  • Skips the risky. Cloud-only placeholders, hard links of the same file, junctions and symbolic links are never reported or followed.

Compare and synchronise folders

Two panes make it easy to see what is different. Two commands do something about it.

Compare folders

Marks the files that exist on only one side or differ by name, size or date, so you can copy exactly those with F5.

Synchronise folders

  • Left to right, right to left, or both ways (the newer file wins).
  • Replace existing files, only when the source is newer, or when size or date differ.
  • Whole folder trees are copied through the queue. Nothing is deleted.

Queue

Press Add to queue and the job waits. Start it when you are ready. Move jobs up or down, pause everything with Shift+F11, or toggle the queue panel with Ctrl+F11.

Sources list

Add files, add a folder, paste what you copied in Explorer, or drop items in. Each row shows its name, location and size. Remove what you do not want.

History

Every job is kept with date, mode, result, file count, size, time, destination and sources. Search it, run a job again, open its destination or clear it.

Verify and report

Check each copy with a checksum, then save an HTML or CSV report, or a checksum list. Move deletes the original only after the copy is checked.
