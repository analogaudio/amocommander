Find files and folders, in many places at once

Press F12 (or Alt+F7). Type part of a name, add text to look for inside the files, and search several folders or whole drives in one go.

Search

  • Files, folders or both. Switch with one key, or search by wildcard: *.pdf, report*, several masks separated with ;.
  • Many locations. Type C:\;D:\ in Search in to search both drives, or press Browse to pick a folder (hold Shift to add it to the list).
  • Inside files. Add the text you want to find, with Match case and Search subfolders as toggles.
  • Live results. Hits appear while the search runs, and Stop ends it at any time.

Work with the results

  • Sort. Click Name, Folder, Size or Modified, and click again to reverse. New hits stay in order while searching.
  • Select several. Ctrl or Shift click, or Ctrl+A.
  • Copy, cut, drag. Ctrl+C and Ctrl+X, then paste in a pane or Explorer, or drag the selection out to copy or move.
  • Right-click. The Windows menu for the files, plus Go to, View and Copy path.
  • Go to or View. Go to shows the item in the active pane, View opens it in the viewer.

When a file already exists, you decide

Copy, move and unpack all use the same choices and the same keys. Pick once for the whole job, or file by file.

  • Choose what happens before you start: ask me, overwrite, skip, keep both, rename the existing file, replace if older, replace if different.
  • Or press a key to start at once with that choice: A overwrite all, K skip all, B keep both, R rename existing, L replace if older, D replace if different.
  • Q adds the job to the queue, X or Esc cancels, and Enter or the first letter of the button starts now.
  • Unpacking only the files you need? The overwrite choices appear straight away, with no extra form.

In the conflict dialog

  • It shows the new file and the existing one side by side, with size, date and which is newer.
  • O overwrite, S skip, B keep both, R rename the existing file, L replace if older, D replace if different.
  • A overwrite all and K skip all, or tick Do this for all conflicts in this job.
  • Q adds this file to the queue: the job carries on with the others and asks again at the end.

Method stack

Tags

Name swaps and case-only changes work. Reserved names (CON, NUL, COM1...), names over 255 characters and long paths are flagged. Presets (.amorn) save your method stack.

How it matches

  • Identical content. Compares size first, then a SHA-256 of the first 64 KB, then of the whole file. Only true copies are grouped.
  • Fast modes. Same name and size, or same size and modified time, when you want speed over a byte-exact check.
  • Options. Include subfolders, set a minimum size, drag folders in or use Add folders. Also opens from Find files.

How it clears

  • Mark. Click a box or press Space. Or Keep newest, Keep oldest or Keep first.
  • Delete or move. Marked files go through the transfer queue, to the Recycle Bin when the drive has one.
  • Always one left. At least one copy of every group is kept, and each file is checked again (size and date) before anything is queued.
  • Skips the risky. Cloud-only placeholders, hard links of the same file, junctions and symbolic links are never reported or followed.

Compare and synchronise folders

Two panes make it easy to see what is different. Two commands do something about it.

Compare folders

Marks the files that exist on only one side or differ by name, size or date, so you can copy exactly those with F5.

Synchronise folders

  • Left to right, right to left, or both ways (the newer file wins).
  • Replace existing files, only when the source is newer, or when size or date differ.
  • Whole folder trees are copied through the queue. Nothing is deleted.

Queue

Press Add to queue and the job waits its turn. Press Copy, Move or Unpack and it starts at once, alongside the jobs already running. Drag a job to reorder, choose Run next, or use Priority to pause the running jobs, start this one, and resume the others when it ends.

Start together, or one by one

Start a single job at the same time as the others, start them all together, pause all or resume all. Jobs on different drives already run together by themselves.

History

Every job is kept with date, mode, result, file count, size, time, destination and sources. Search it, run a job again, open its destination or clear it.

Verify and report

Check each copy with a checksum, then save an HTML or CSV report, or a checksum list. Move deletes the original only after the copy is checked.
