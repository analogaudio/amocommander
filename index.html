Everything a file manager should do

Put two folders side by side and work between them. The basics are fast, the details are all there, and nothing is hidden behind a menu you have to hunt for.

Two panes

Open two folders side by side. Copy or move to the other pane with one key, or open the same folder in both.

Drives and free space

Jump between C, D, E and network drives from the drive bar. The free space for each pane is always on screen.

Easy navigation

Back, forward and up buttons, a clickable path, refresh, and pinned folders for the places you use most.

Sortable columns

Name, extension, size, date, time and attributes. Click a column to sort, in either pane.

File operations

Copy, move, rename, make a new folder and delete, from the toolbar, the keyboard or the right-click menu.

Find and filter

Search for files by name, or filter the current list as you type to see only what matches.

Quick view and hidden files

Preview a file in the other pane, and show or hide hidden and system files with one button.

Terminal, admin and themes

Open a terminal in the current folder, run as administrator when you need to, and switch between light and dark.

Select a file and press a key. Everything opens inside AMO Commander, so you never leave the window or hunt for another tool.

Queue

Press Add to queue and the job waits. Start it when you are ready. Move jobs up or down, pause everything with Shift+F11, or toggle the queue panel with Ctrl+F11.

Sources list

Add files, add a folder, paste what you copied in Explorer, or drop items in. Each row shows its name, location and size. Remove what you do not want.

History

Every job is kept with date, mode, result, file count, size, time, destination and sources. Search it, run a job again, open its destination or clear it.

Verify and report

Check each copy with a checksum, then save an HTML or CSV report, or a checksum list. Move deletes the original only after the copy is checked.
